# TP Programación - Análisis de Ventas

Este proyecto implementa una solución en Python para el procesamiento y análisis de datos comerciales simulados de una pequeña empresa (Escenario B).

## Estructura del Proyecto

* **`datos/`**: Contiene el archivo de origen en formato CSV (`ventas.csv`).
* **`scripts/`**: Código fuente en Python para el procesamiento numérico (`analisis_ventas.py`).
* **`resultados/`**: Reportes y gráficos generados de forma automática (`evolucion_ventas.png`).

## Requerimientos Resueltos
1. **Cálculo de Ventas Totales**: Multiplicación acumulada de cantidad por precio.
2. **Producto Más Vendido**: Identificación del artículo con mayor volumen de salida.
3. **Evolución Mensual**: Agrupación cronológica de las ganancias.
4. **Gráfico Estadístico**: Exportación visual automática con Matplotlib.
